# チャンネル表 v0（頭部フェーズ）

構成: Mega=運動・安全ノード／ESP32=味覚・湿潤系ノード／PC=AI・音声・統合。
サーボはPCA9685 ×2（**在庫表に無いため要発注**）。電源グループは power_system_v0.md と対応。

---

## I2Cアドレスマップ

| アドレス | デバイス | バス | 設定 |
|---|---|---|---|
| 0x29 | TCS34725（カラー） | ESP32 | 固定 |
| 0x40 | PCA9685 #1 | Mega | ジャンパ無し |
| 0x41 | PCA9685 #2 | Mega | A0ハンダ |
| 0x44 | INA219 #A（レールA監視） | Mega | A1ジャンパ |
| 0x45 | INA219 #B（レールB監視） | Mega | A0＋A1ジャンパ |
| 0x48 | ADS1115（味覚AD） | ESP32 | ADDR→GND |
| 0x49 | ADS1115 増設予約 | ESP32 | ADDR→VDD |

⚠ **INA219のデフォルトは0x40でPCA#1と衝突する。必ず0x44/0x45へ変更してから接続。**

## 固定安全ロジック（LLMに委譲しない層）

| 条件 | 検知 | 固定動作 |
|---|---|---|
| 漏水 | A0〜A2 閾値超え | OE=HIGH（全サーボ停止）＋全ポンプOFF＋PCへLEAKイベント |
| トレー未装着 | D2 | 口内系コマンド（JAW_OPEN含む）拒否 |
| タンク満水 | D3 | 食品受入停止。DRAIN系以外の口内系拒否 |
| E-STOP押下 | D18 | 状態遷移HALT・コマンド受付停止 |
| ポンプ連続駆動超過 | ソフトタイマ | 強制OFF＋詰まり疑いフラグ |
| レールB過電流 | INA219 @0x45 が2A超×2秒 | レールBサーボ停止（5A級降圧導入までの暫定） |
