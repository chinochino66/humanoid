2026-08-06

## 決定

L系とR系を単一リポジトリ `chinochino66/humanoid` 内のディレクトリ分離（`docs/L/` と `docs/R/`）で運用する。蓮冥頭部 開発手順書 §1.5の「別Gitリポジトリ」要求を改訂した。

## 改訂した文書

蓮冥頭部 開発手順書 Version 2.0 → Version 2.1（2026-08-06）

手順書はPDFでありgit管理外のため、改訂の経緯は本書にのみ記録される。

## 知財上の担保

`docs/R/` は電気的な軸予約（チャンネル番号・在庫型番の紐付け）のみを扱い、InMoov由来の形状・寸法・STL・メッシュへの参照を一切含まない。

R-Phase 0 の完了ゲート「R系にInMoov由来ファイルが無いこと」は、リポジトリの物理的分離ではなく由来台帳（`R_IP_Provenance_Register`）で担保する。
