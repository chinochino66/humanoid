## 変更前の体系（H-Phase）

蓮冥頭部 H-Phase 0-24 改訂手順書（2026-08-03改訂）に基づく、H0〜H24の単一時系列フェーズ体系。InMoov学習機・独自商用頭部・咀嚼機構が同一のフェーズ番号列に混在していた。

## 変更後の体系（L/R/S/M）

| 系統 | 内容 |
|---|---|
| L | InMoov 100%学習機（非商用。L5で凍結） |
| R | 独自商用頭部（白紙CADから新規設計。2027年R1-R9） |
| S | 安全・制御・知覚（InMoov非由来。R系へ再利用可） |
| M | 実咀嚼・搬送・洗浄・排出（2034年以降） |

対応表：

| 旧（H-Phase） | 新（L/R/S/M） |
|---|---|
| H0-H1 | L0-L1 |
| H2-H5 | L2-L5 |
| H6-H10 | R5-R9 + S1-S4 |
| H11-H13 | S3-S6 |
| H14 | R10 |
| H15-H24 | M0-M9 |

## 変更理由

H-Phase体系は、InMoov学習機（非商用）と独自商用頭部の設計を同一の時系列フェーズに混在させており、以下の問題があった。

1. 非商用（InMoov由来）の形状・寸法・メッシュと、商用新設計の情報が同一文書内で参照される構造になっており、知財上の混入リスクがあった。
2. 咀嚼機構（M系、2034年以降）に紐づく決定（例：首サーボ発注の保留）が、咀嚼顎を載せないL系の意思決定をブロックしていた。
3. フェーズ番号だけでは、各設計項目がどの製品ライン（学習機／商用機／安全系／咀嚼系）に属するかを判別できなかった。

## L系を非商用学習機として分離する知財上の根拠

L系はInMoov公式設計（Attribution-NonCommercial ライセンス、出典 inmoov.fr）に100%準拠して製作する学習機であり、形状・寸法・STL・メッシュはInMoov由来のものをそのまま使用する。このライセンス条件下では、L系の成果物を商用製品へ転用することはできない。

そのためL系はL5到達をもって凍結し、以降の開発をR系（白紙CADからの新規設計）へ完全に切り離す。R系の文書にはInMoov由来の形状・寸法・メッシュへの参照を一切含めない（`docs/R/reserved_axes.md` はこの運用ルールに従う）。

## 今回修正した設計上の誤り一覧

1. **稼働時間計算の測定点誤り**：旧記述「76.8Wh ÷（12.8V×1.6A）≒3.7時間」は、1.6Aがレール A（5.8V）側のピーク電流であり、電池側12.8Vの電流ではなかった。全負荷を電池側12.8V等価電流へ換算し、降圧効率を明示した上で再計算する（`docs/S/power_tree.md`）。
2. **PTC諸元の誤読**：部品表の「RXEF72」の72は耐圧72Vであり、保持電流ではなかった。実物はRXEF250相当（保持2.5A／トリップ5.0A／72VDC／直列抵抗0.05Ω）。「PTCが過電流保護を担う」という記述は「配線保護に限定される」へ訂正する。保護協調（レギュレータ実用電流との不整合、高温側の保持電流低下等）は未整理のままOPEN_ISSUESへ登録する。
3. **首サーボ発注保留の根拠誤り**：旧文書は将来の咀嚼顎質量（FutureJaw_MassEnvelope）確定まで首サーボ発注を保留としていた。咀嚼機構はM系（2034年以降）でありR系頭部にのみ搭載される一方、L系はL5で凍結される学習機であり咀嚼顎を載せない。したがってL系の首サーボ選定を咀嚼顎質量確定でブロックする根拠がなかった。
