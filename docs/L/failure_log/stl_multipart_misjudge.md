# 失敗記録：STL複数部品の見落としによる判断誤り

版数: v1
改訂日: 2026-08-06
準拠文書: 器創造計画 2026-2033（改訂基準日 2026-08-03）
系統タグ: L（InMoov 100%学習機。首上下サーボ規格判断の記録）
変更履歴:
- v1 2026-08-06 新規作成。`docs/OPEN_ISSUES.md` #39の一時的な誤判断（首上下サーボ「未確定」への撤回）の経緯を失敗記録として切り出した。

---

## 1. 発生日

2026-08-06

## 2. 事象

NeckServoHolderV2 に HS-805BB が物理的に収まらないと判断し、首上下軸のサーボを「未確定」として記録した。実際にはSTLに同一形状のL字ブラケットが2個含まれており、判断は誤りであった。

## 3. 原因

スライサーの外形表示（55.0 × 58.5 × 22.0mm）のみを根拠とし、STLの中身（部品点数・形状）を確認しなかった。また構造をサーボを内包する箱型と推定したが、実際は左右から挟むブラケットであった。

## 4. 影響

`docs/OPEN_ISSUES.md` #39 を影響度「高」へ引き上げ、首2軸のサーボ確定を一時撤回した。調達済みのHS-805BB 2個のうち1個の用途が未定になると誤って記録した。実害は文書上のみで、部品の誤発注は発生していない。

## 5. 是正

2026-08-06中に公式 Hardware and BOM の記載（https://inmoov.fr/default-hardware-map/）とBlenderでのSTL目視確認により訂正した。

## 6. 教訓

1. **スライサーの外形表示は「STL全体のバウンディングボックス」であり、単一部品の寸法ではない。**複数部品が含まれるSTLでは実際の部品寸法と一致しない。
2. 寸法から嵌合可否を判断する前に、STLをBlender等で開いて部品点数と構造を目視確認する。
3. 公式ドキュメントに組立手順が無い場合でも、**Hardware and BOM ページにサーボ割当が記載されている場合がある。**チュートリアルだけを確認対象としない。
