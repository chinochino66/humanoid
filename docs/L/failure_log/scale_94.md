# 失敗記録：94%スケール不採用

改訂日: 2026-08-04
準拠文書: 器創造計画 2026-2033（改訂基準日 2026-08-03）
系統タグ: L（InMoov 100%学習機。頭部スケール決定の記録）
変更履歴:

## 1. 何があったか（旧文書からの確認事実）

- 旧H-Phase体系のH-Phase 0で、頭部のBlender空間予約（3Dモデル上での機構配置検討）を**94%スケール**を基準に作成した。
- その後のH-Phase 1で「CALIBRATOR」比較を行い、**100%スケールの採用が確定した**（`docs/archive/2026-08-03_power_system_hphase.md` 冒頭「採用スケール: 100%（H-Phase 1 CALIBRATOR比較にて確定）」、`docs/archive/2026-08-03_servo_comparison_hphase.md` 表題「頭部フェーズ／スケール100%」）。
- 結果として、94%基準で作成済みだったBlender空間予約は、100%採用に伴い**再作成が必要**になった（旧文書に「⚠ H-Phase 0のBlender空間予約は94%基準で作成されているため、100%採用に伴う再作成が必要。別課題として管理する」と記載）。

**移行元文書に残っていない情報**：「CALIBRATOR比較」の具体的な比較項目・数値・判断過程は、移行対象の3文書（power_system／servo_comparison／channel_map、いずれも `docs/archive/` に退避済み）のいずれにも記録が見当たらない。名称のみが残っている状態であり、本書執筆時点で再現できない。

## 2. 何が失敗だったか

- **スケールに依存する成果物（空間予約）を、スケール確定前に暫定値（94%）で作り込んでしまった。**100%への変更が判明した時点で手戻り（Blenderモデルの再作成）が発生した。
- **重要な意思決定（スケール確定）の判断根拠が文書化されずに失われた。**「CALIBRATOR比較にて確定」という結論だけが残り、比較項目・数値・却下理由が追跡できない。今回のL/R/S/M移行でも、この経緯を裏付ける一次資料は見つからなかった。

## 3. 教訓（今後の運用への反映）

- 空間予約・機構配置などスケールに依存する成果物は、**スケール確定を待ってから着手する。**確定前に着手する場合は、暫定値であることと、確定後に再作成が必要になり得ることを成果物自体に明記する。
- 重要な意思決定は、**判断根拠（比較項目・数値・結論）をその場で文書化する。**名称だけの記録は、後から検証も再利用もできず、失敗の再発防止に使えない。本移行で作成した文書群（`docs/decisions/2026-08-03_lrsm_migration.md` 等）は、この教訓を踏まえて意思決定の根拠を残す形式を踏襲している。

## 4. 現在の状態（2026-08-04時点、未確認）

採用スケール100%は確定済みであり、本移行後の文書（`docs/L/servo_assignment_L2.md`・`docs/reference/servo_datasheets.md` 等）は100%スケール前提で作成した。ただし以下は移行元文書からは確認できず、`docs/OPEN_ISSUES.md` へ登録する：

- 94%基準で作成されたBlenderモデルが実際に100%へ更新済みかどうか
- CALIBRATOR比較の詳細記録が別途どこかに存在するか（存在すれば本書へ転記し、存在しなければ「記録なし」を確定させる）
