# チャンネル表 v1（頭部フェーズ）

準拠: `蓮冥頭部 H-Phase 0-24 改訂手順書`（2026-08-03改訂）
電源グループは `power_system.md` と対応。

**構成（制御四層）**

| 層 | 実体 | 役割 | 状態 |
|---|---|---|---|
| 第1層 | 胴体内AIコンピュータ（未選定） | 音声認識・LLM・TTS・視覚・ログ | **未実装**（暫定でノートPCが代行） |
| 第2層 | Arduino Mega | サーボ指令、位置・電流取得、状態機械 | 実装中 |
| 第3層 | 独立安全コントローラ（未選定） | 非常停止・漏水・過電流・過熱・WDT・電源遮断 | **未実装**（暫定でMegaが兼務） |
| 第4層 | LiFePO4 + BMS | 残量・温度監視、低電圧シャットダウン | 未接続 |

⚠ **第3層の兼務は暫定。**Megaがハングすれば安全系も同時に死ぬ。H-Phase 12で分離する。

### 味覚JSONスキーマ v2

```json
{
  "ts": 0,
  "raw":        { "ph_mv": 0, "tds_mv": 0, "temp_c": 0, "rgb": [0,0,0], "voc_mv": 0 },
  "calibrated": { "ph": 0.0, "ec_us_cm": 0, "temp_c": 0.0 },
  "estimated":  { "sourness": 0.0, "saltiness": 0.0, "sweetness": 0.0, "aroma": 0.0 },
  "confidence": 0.0,
  "flags":      { "sensor_fault": false, "uncalibrated": false, "rinse_required": false }
}
```

**raw / calibrated / estimated / confidence を分離する。**pHを酸味、導電率をイオン量、VOCを香りの手掛かりとして扱い、**五味そのものと断定しない**（H-Phase 11）。

## 7. 固定安全ロジック（AI・LLMに委譲しない層）

| # | 条件 | 検知 | 固定動作 | 担当層 |
|---|---|---|---|---|
| 1 | 漏水 | A0〜A2 閾値超え | **喉ゲートを閉位置へ駆動 → 完了確認 → OE=HIGH → 全ポンプOFF → アクチュエータ電源遮断** | 第3層 |
| 2 | トレー未装着 | D2 | 口内系コマンド（JAW_OPEN含む）拒否 | 第2層 |
| 3 | タンク満水 | D3 | 食品受入停止。DRAIN系以外の口内系拒否 | 第2層 |
| 4 | E-STOP押下 | 物理NC接点 | **アクチュエータ電源を物理遮断。**手動確認まで再始動禁止 | 第3層 |
| 5 | ポンプ連続駆動超過 | ソフトタイマ | 強制OFF＋詰まり疑いフラグ | 第2層 |
| 6 | レール過電流 | INA219 が2A超×2秒 | 該当レールのサーボ停止 | 第2層→第3層 |
| 7 | **過熱** | A3 が閾値超え | 新規動作禁止 → 中立復帰 → 遮断 | 第3層 |
| 8 | **通信断（第1層）** | 受信タイムアウト | **新規動作禁止。中立保持または力解放** | 第2層 |
| 9 | **ハートビート停止（第2層）** | D10 のWDT | アクチュエータ電源遮断 | 第3層 |
| 10 | **BMS低電圧** | BMS通知 | 新規動作禁止 → ログ保全 → 制御シャットダウン | 第3層 |
| 11 | **モジュールID不明** | D8/D9 | **顎駆動へ電力を供給しない** | 第3層 |
| 12 | 待機タイムアウト | ソフトタイマ | OE=HIGH（保持電流遮断）。復帰は OE=LOW→目標角 | 第2層 |

**#1の順序が重要。**先にOE=HIGHにすると喉ゲートを閉じられなくなる。**閉じてから止める。**

**#4と#9は電気的に第2層から独立していること。**Megaがハングしても働くこと（H-Phase 12完了ゲート）。

## 8. 顎モジュールモード

| モード | 条件 | 顎駆動 |
|---|---|---|
| `EXPRESSION_JAW` | ID=00 | 表情・発話・味見のみ。**咀嚼不可** |
| `TASTE_ONLY` | 任意 | 顎は最小開口。味覚測定のみ |
| `MASTICATION_BENCH` | ID=01 かつ 頭部外 | ベンチ治具でのみ許可 |
| `MASTICATION_INSTALLED` | ID=01 かつ 全安全条件成立 | H-Phase 20以降 |

**表情顎では咀嚼モードへ遷移できない**（H-Phase 13完了ゲート）。
