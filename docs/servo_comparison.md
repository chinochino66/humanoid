# サーボ仕様比較 v1（頭部フェーズ／スケール100%）

準拠: `蓮冥頭部 H-Phase 0-24 改訂手順書`（2026-08-03改訂）
採用スケール **100%** のため、InMoov公式指定のトルク基準がそのまま適用できる。

---

## 0. 選定方針

1. **荷重帯でサーボを分ける。**17軸を同一型番で揃える必要はない
2. **首サーボは将来の咀嚼顎質量を織り込むまで確定しない**（§6参照）
3. **公称値には条件がつく。**条件を書かない数値は採用しない
4. 電源はレールA=5.8V／レールB=5.0Vを前提とする（`power_system.md` §4）

## 6. 首サーボ選定を保留する理由 ★

**改訂手順書 H-Phase 2 は、将来の咀嚼顎の質量ダミーを載せた許容領域（`FutureJaw_MassEnvelope_v0`）の作成を求めている。**

現在の頭部に加えて、H-Phase 20では以下が追加される。

- 金属サブフレームの咀嚼顎
- 交換式人工歯、舌パドル
- 荷重センサー、人工唾液回路
- 下顎外装・下顎シリコン皮膚

**今の頭部質量だけで首サーボを確定すると、H-Phase 20で首ごと作り直しになる。**手順書の「1からやり直しになる条件」に該当する。

**判定に必要なもの（H-Phase 2で取得する）**

1. 現在の頭部質量と重心位置の実測
2. `FutureJaw_MassEnvelope_v0` による将来質量・重心の想定値
3. 首の回転軸から重心までの距離 → 必要トルクの計算
4. NeckServoHolderV2 / SkullServoFixV5 の実寸とサーボ外形の照合
5. レールB 5.0V動作時のトルク低下（公称6V比で約2割減）の織り込み

**上記が揃うまで、首サーボは発注しない。**

## 7. 顎の角度リミット

| 項目 | 値 | 根拠 |
|---|---|---|
| 試験手順 | 閉口 → 5° → 10° → **15°** | 改訂手順書 H-Phase 5 |
| ハードコード上限 | **20°** | InMoov公式注記（超過で破損リスク） |
| 同時駆動 | 首との同時駆動を禁止 | レールB電流予算 |

**試験は15°まで。上限20°はソフトウェア側の絶対リミット。**両者を混同しないこと。加えて**機械ストッパーとソフトウェア制限の両方**を働かせる（H-Phase 5完了ゲート）。

## 8. 決めること

1. **MG92Bの高さ31mmを、印刷済みサーボマウントに実測で当てる**（入らなければSG92RかMG90Sへ変更）
2. 頭部質量・重心の実測と `FutureJaw_MassEnvelope_v0` の作成 → 首サーボ確定
3. jawをMG996R（安価）とDS3218（余裕）のどちらにするか
4. 将来の咀嚼顎アクチュエータは本表の対象外。H-Phase 15の要求仕様策定後に別途選定する
