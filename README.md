## 概要

InMoov公式設計に100%スケールで準拠した学習機（L系）を土台に、独自商用頭部（R系）・共通制御技術（S系）・将来の実咀嚼機構（M系）を段階開発するプロジェクトである。

## 体系概要 L/R/S/M

| 系統 | 内容 |
|---|---|
| L | InMoov 100%学習機（非商用。L5で凍結。R系へ形状・型・STLを移さない） |
| R | 独自商用頭部（白紙CADから新規設計。2027年R1-R9） |
| S | 安全・制御・知覚（InMoov由来ではない。R系へ再利用可） |
| M | 実咀嚼・搬送・洗浄・排出（2034年以降） |

## 現在地

L-Phase 2（首・頭部回転の基礎）進行中、2026年8月時点。

## 知財の注意

L系はInMoov公式設計（Attribution-NonCommercial、出典 inmoov.fr）に準拠した非商用の学習機であり、L系の形状・寸法・STL・メッシュをR系（独自商用頭部）へ転用しない。詳細は `docs/README.md`「知財境界の明示」を参照。
